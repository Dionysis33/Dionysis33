## Project Highlights

### WindPower Digital Twin

A forecasting-first research repository for wind-power modelling and diagnostics.

The project includes:

- Strict raw-data validation and coverage-aware exploratory analysis
- Leakage-aware feature engineering and temporal data splitting
- Persistence, Linear Regression, Random Forest, XGBoost, and MLP benchmarks
- Controlled GRU, LSTM, Transformer, and supplementary sequence-model experiments
- Residual and park-level diagnostic analysis
- Graph data contracts, graph forecasting baselines, and spatial sensitivity analysis
- Reproducible scripts, audit documentation, CI workflows, and repository safety checks
- A local Django interface for read-only inspection of curated research artifacts

The repository is intentionally presented as a forecasting and diagnostics research pipeline rather than as a deployed industrial digital-twin or production PHM platform.

### DiffPriv-Gateway

A Python-based privacy-preserving analytics middleware project designed around the needs of small and medium-sized organisations.

It demonstrates:

- Laplace and Gaussian Differential Privacy mechanisms
- Privacy-budget and utility awareness
- Modular Python implementation
- Synthetic datasets
- Automated testing with pytest
- Continuous integration
- GDPR-oriented documentation, security guidance, and accountability

### Solar PV Forecasting & Anomaly Detection

An applied machine-learning project using photovoltaic generation and weather-sensor data.

It demonstrates:

- Time-series preprocessing and sequence generation
- An unsupervised LSTM Autoencoder
- Reconstruction-error-based anomaly detection
- Modular Python source code
- Saved model artifacts and visual evaluation outputs
- Predictive-maintenance-oriented interpretation

### Cloud Inventory Graph Database

A NoSQL-first inventory-management database project with Neo4j as its primary operational database.

It demonstrates:

- Graph data modelling
- Cypher constraints, seed data, and operational queries
- Neo4j Aura
- MariaDB as a supporting relational layer
- Python-based raw and processed data validation
- Architecture diagrams, evidence, and automated repository checks

### Enterprise Task Management System

A full-stack Java application demonstrating enterprise backend architecture.

It includes:

- Java 21 and Spring Boot 3.3
- Spring Security 6
- Authentication and role-based access control
- Controller, Service, and Repository layers
- DTO and Repository patterns
- CRUD, search, and filtering workflows
- MySQL persistence
- Maven and GitHub Actions
